# File Sharing Application

## Project Overview

This is a serverless file-sharing application built using AWS Lambda, S3, and pre-signed URLs for secure and efficient file uploads and downloads.

## Features

- **Serverless Architecture:** Utilizes AWS Lambda for scalable backend logic without managing servers.
- **Pre-signed URLs:** Ensures secure file uploads and downloads by generating temporary URLs with restricted permissions.
- **S3 Integration:** Files are directly stored in Amazon S3 for high availability and durability.
- **User-Friendly Interface:** Simple UI for uploading, sharing, and downloading files.

## Tech Stack

- **AWS Lambda** - Backend logic
- **Amazon S3** - File storage
- **Pre-signed URLs** - Secure upload/download mechanism
- **Node.js & Express** - API logic for generating URLs
